# Contributing to CV Buddy

Thank you for your interest in contributing to **CV Buddy**!

## Reporting Issues

If you encounter a bug or a job board form that isn't detected properly:
1. Check the [existing issues](https://github.com/Sandun-S/Job-Autofill-AI/issues) to see if it has already been reported.
2. Open a new issue with:
   - Browser name and version (e.g., Chrome 130, Firefox 132)
   - Steps to reproduce
   - Type of form or ATS platform (e.g., Greenhouse, Lever, Workday, custom) — avoid pasting personal data or API keys.

## Submitting Pull Requests

1. Fork the repository: `https://github.com/Sandun-S/Job-Autofill-AI`
2. Create a feature branch:
   ```bash
   git checkout -b feature/your-feature-name
   ```
3. Make your changes and test them locally as an unpacked extension in Chrome/Edge/Brave and/or as a temporary add-on in Firefox (128+).
4. Ensure no API keys, personal profile data, or packaged `.zip` artifacts are committed.
5. Commit your changes and open a Pull Request against `main`.
